# GRAF Compatibility with wsrep_view Entity Type

**Date**: October 1, 2024  
**Status**: ✅ **FULLY COMPATIBLE**

## Summary

GRAF has been updated to fully support the new `wsrep_view` entity type from grap3, treating it alongside the existing `view` (gcomm) entity type.

## Changes Made to GRAF

### Before
```python
elif et == "view":
    # Only handled entity_type="view"
```

### After
```python
elif et == "view" or et == "wsrep_view":
    # Handles both entity_type="view" and entity_type="wsrep_view"
    layer = (e.get("view_layer") or ("wsrep" if et == "wsrep_view" else "gcomm")).lower()
```

## Key Features

1. **Dual Entity Type Support**
   - `entity_type="view"` → gcomm layer (low-level cluster membership)
   - `entity_type="wsrep_view"` → wsrep layer (high-level replication)

2. **Automatic Layer Detection**
   - Uses `view_layer` field if present
   - Falls back to entity type (`wsrep_view` → wsrep, `view` → gcomm)

3. **Unified State Machine**
   - Both view types update the same state machine under `state_machine["view"]`
   - wsrep views stored as `state_machine["view"][cluster_key]["wsrep_view"]`
   - gcomm views stored as `state_machine["view"][cluster_key]` (root level)

4. **Frame Structure**
   - wsrep view data appears in frames under `views[cluster_key].wsrep`
   - gcomm view data appears in frames under `views[cluster_key]` (root level)

## Usage

```bash
# Extract with grap3 (generates wsrep_view entities)
./grap3 error.*.log --format=json > entities.json

# Build frames with graf
./graf entities.json -o frames.json

# Or stream processing
./grap3 error.*.log --format=json | ./graf --ndjson > frames.ndjson
```

## Backward Compatibility

✅ **Fully backward compatible** with v2 grap output:
- v2 used `entity_type="view"` for both layers
- v2 distinguished layers via `view_layer` field
- graf continues to support this format

✅ **Forward compatible** with v3 grap3 output:
- v3 uses `entity_type="wsrep_view"` for wsrep layer
- v3 uses `entity_type="view"` for gcomm layer
- graf automatically detects and handles both

## Field Mapping

### grap3 Output → graf Frame

| grap3 Field | Frame Location | Description |
|-------------|----------------|-------------|
| `entity_type: wsrep_view` | `event.entity_type` | Triggers wsrep processing |
| `view_layer: wsrep` | `views[cluster].wsrep.view_layer` | Layer identifier |
| `group_uuid` | `views[cluster].wsrep.group_uuid` | Cluster/group UUID |
| `cluster_uuid` | `views[cluster].wsrep.cluster_uuid` | Same as group_uuid |
| `view_id` | `views[cluster].wsrep.view_id` | Complete view ID |
| `view_seq` | `views[cluster].wsrep.view_seq` | Sequence number |
| `status` | `views[cluster].wsrep.status` | PRIMARY/NON-PRIMARY |
| `protocol_version` | `views[cluster].wsrep.protocol_version` | Protocol version |
| `capabilities` | `views[cluster].wsrep.capabilities` | Array of capabilities |
| `member_count` | `views[cluster].wsrep.member_count` | Number of members |
| `members` | `views[cluster].wsrep.members` | Node names |
| `member_details` | `views[cluster].wsrep.member_details` | Full member info |
