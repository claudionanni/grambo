# Gramboo Python Analyzer (Status)

`gramboo.py` is the transitional analyzer that preceded the `graa` + `grap` pipeline. We keep it in the repo for legacy workflows, but it is no longer part of the primary toolchain.

- Prefer the current pipeline documented in `docs/README.md`.
- Use `grax` for end-to-end processing (includes the SST viewer and timeline UI).
- Only reach for `gramboo.py` when you need feature parity with historic scripts.

Future work will focus on the `graa`/`grap` stack; this document intentionally stays short to reflect that shift.
