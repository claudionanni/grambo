┌──────────────────────────────────────────────────────────────────────────────┐
│ 6. DETECTION LOGIC                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

NON-PRIMARY Detection:
  • Checks: status, cluster_state, view_status fields
  • Matches: "NON-PRIMARY", "NON_PRIM", or any containing "NON"
  • Case-insensitive matching
  • Works with both v2 and v3 data formats

Quorum Event Detection:
  • Primary: Matches by group_uuid → cluster_uuid → cluster_ref
  • Fallback: Uses _default key if no match
  • Timestamp filtering: Only shows events at or before current frame
  • Fields: event_type, quorum_status, severity, event_text
